# 🛍️ E-commerce Sales

* Site criado para estudo e suas informações são meramente ilustrativas.

## Descrição
O E-commerce é um projeto de loja virtual desenvolvido com tecnologias modernas, oferecendo uma experiência de análise de métricas, controle e otimização de produtos, clientes e vendas.

## 🚀 Funcionalidades e Páginas

O projeto foi criado para atender o vendedor/administrador responsável.

* Página Inicial (index.html): Sistema de login.
* Dashboard (dashboard.html) : Apresentação das estatísticas da origem dos clientes, o valor total das vendas de cada mês durante o ano, categoria de produtos  e sua quantidade vendida em cada uma, pedidos por Estado e o Top 5 de produtos mais vendidos.
* Vendas (sales.html) : Mostra as informações do pedido e nome do cliente e quantidade total referente a cada processo da coluna Status.
* Clientes (clients.html): Apresenta informações completas dos clientes, contendo nome, e-mail, CPF, data de pedido, valor gasto e origem da plataforma que ele encontrou a loja.
* Produtos (products.html) : Estoque de produtos, com informações de quantidade de itens e o total da loja, sistema com mudança de foto e adição de mais mercadorias.
* Funcionalidades gerais : Todas as páginas (exceto Sistema de login).
  * Conta com as informações no cabeçalho :
  * Nome de usuário que está acessando, nome da empresa e cargo
  * Tem a funcionalidade  de Exporta e Importar dados
  * Campos de busca (apenas ilustrativo)
 
## 🎨 Diferenciais do Design & Código

### Diferenciais Técnicos (Código)

* Arquitetura Multi-página Estruturada: Separação clara das regras de negócio em visões dedicadas para Dashboard, Vendas, Clientes e Produtos.

* Padronização do Layout: Reaproveitamento consistente do menu lateral e do cabeçalho em todas as páginas, mantendo a integridade do código.

* Manipulação e Exportação de Dados: Estrutura pronta para suportar operações completas de CRUD (criação, leitura, atualização e exclusão) e geração de relatórios (PDF e CSV).

* Organização dos Ativos: Separação limpa de scripts, folhas de estilo e recursos multimídia na estrutura de pastas.

### Diferenciais de Design (UI/UX)

* Identidade Visual Unificada: Linguagem estética padronizada, garantindo a mesma experiência visual em todos os módulos do sistema.

* Foco em Sistemas Administrativos (Backoffice): Layout profissional focado em usabilidade, leitura rápida de tabelas e navegação contínua.

* Consistência Semântica nos Ícones: Uso padronizado de iconografia para sinalizar ações essenciais (exportar, filtrar, navegar).

* Distribuição Responsiva dos Elementos: Organização em grid/cards adaptável para a exibição fluida de métricas, tabelas detalhadas e formulários.

## 🛠️ Tecnologias Utilizadas

### Front-end & Estrutura

* HTML5 Semântico: Estruturação das páginas com tags modernas para melhor acessibilidade e SEO.

* CSS3: Estilização responsiva, layout em Grid/Flexbox e customização visual dos componentes e tabelas.

* JavaScript (JS): Manipulação de elementos na tela, comportamento interativo dos menus e lógica do front-end.

### Bibliotecas & Recursos Visuais

* Font Awesome / Boxicons: Biblioteca de ícones vetoriais integrados para sinalização visual das ações e menus.

* Chart.js / ApexCharts: Biblioteca de visualização de dados para renderização dos gráficos de estatísticas e conversão.

### Hospedagem & Controle de Versão

* Git & GitHub: Versionamento do código-fonte e controle de alterações do projeto.

* GitHub Pages: Hospedagem direta do site e disponibilização do projeto online.
